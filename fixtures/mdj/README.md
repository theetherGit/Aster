# `.mdj` fixtures

Real StarUML files. These are the codec's truth: the parser must open every file here, the golden test must serialise each back to JSON equal to its source (ignoring key order and whitespace, with any exception documented in `DECISIONS.md`).

Fill in the version column from the file's `_type: "Project"` sibling fields where present, or from the repository's history.

## Rules

- Never hand-edit a fixture. If a file needs a smaller case, make a new file in StarUML and save it.
- Each fixture gets a sibling `<name>.snapshot.json` (generated by the parse test, committed) so regressions show as diffs.
- `fixtures/perf/` holds generated large files; they are not golden fixtures and may be regenerated.
- Licence of public files: keep a `SOURCES.md` here listing repo URL and licence for each; drop any file whose licence does not permit redistribution.
