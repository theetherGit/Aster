# UI audit — the lab path, 2026-10-22

Hallmark audit of what a student does in the 24 Oct lab: welcome → new diagram → classes → relationships → save → export, in Modern light and dark and in Classic, at 1440 × 900 and 1366 × 768. Two passes: the screens, walked step by step in the production build and judged by eye; and the code, read against `design.md`, `docs/spec/ui.md` and Hallmark's anti-pattern list. Every finding was checked in the code before anything changed. Only polish was fixed (nothing in the model or the codec), plus one export bug.

## Kept, because a board or the owner settled it

- Import notice's accent side stripe: board 08 draws it.
- "8 classifiers" in the status footer and "Export" without an ellipsis in the top bar: boards 01 and 06 read that way.

## For the owner (settled 2026-10-22)

- After ⌘S the "Saved in this browser only" notice and the "lives only in this browser" banner both offered **Download .mdj** at once. Ruling: the notice stands in for the banner while it is up.
- design.md contradicted itself twice: Type allowed weights 400 and 600 only while CTA voice gave secondary buttons 500; CTA voice listed Cancel as Secondary while every sheet draws it Ghost. Ruling: design.md amended to match the code.

## Deferred (after the lab; none blocks it)

- Toolbox Link and Pin are `disabled`, so a keyboard user never reaches the tooltip that says why; use `aria-disabled` and a guard, as Undo and Redo do. (Behaviour, not polish.)
- Accent tints for "on" states vary from 10 % to 40 % across the toolbox, segments, chips, banner and inspector; one token (`--selection-tint` exists at 8 %).
- Caption-heading tracking drifts between 0.025em and 0.05em; one class string.
- Line-style tiles use a native `title`; the 2026-10-19 ruling moved titles to the Tooltip atom.
- Small copy: "Enter" vs "↩" in hints, "Show Outline" vs "Hide outline", a few sentences built from fragments, straight quotes in one message, "More formats…" and "Clear" are not verbs.
- Raw px in a few organisms (chips 30 px, row heights, two 3–4 px radii) and `motion.ts` durations not read from the tokens.
- Typing within one frame of pressing C can reach the canvas before the name field has focus. Only a script types that fast; noted, not fixed.
