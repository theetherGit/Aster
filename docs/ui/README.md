# UI mockups

`mockups/` holds the source of the "Aster UI Design" canvas (22 artboards). Every app board is `Main.dc.html` with preset props; the wrapper files show which preset each board uses (`layout`, `theme`, `state`, `inspector`, `text-view`, `focus-nav`, `contrast`, `explorer`). `Notation.dc.html` is the UML notation reference sheet. `canvas.json` lists the boards and the design notes.

These are Design Component pages, not runnable on their own; read `Main.dc.html` for the exact chrome structure, tokens and copy. The token table the app must use is in `../spec/ui.md`.
