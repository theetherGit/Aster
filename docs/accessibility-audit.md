# Accessibility audit (WCAG 2.2 AA)

This file records evidence, not verdicts. Nothing here is marked as passing. A criterion passes when the manual script in `docs/manual-a11y-script.md` has been run by a person in VoiceOver on macOS and NVDA on Windows and the run is logged at the bottom of this file. Until then, the rows say which automated test covers part of a criterion and which script step a person must run.

Status words:

- **Automated**: a test in CI checks the stated part. It does not prove the criterion.
- **Manual**: only the scripted human run can settle it. The step number refers to the manual script.
- **Not applicable**: Aster has no such content.
- **Gap**: known missing work, with where it is tracked.

The axe run in CI that the M2.7 prompt asks for is a gap: it needs `@axe-core/playwright`, which waits for the owner's approval of a new dependency and for the lockfile to unfreeze after the 2026-10-24 lab.
