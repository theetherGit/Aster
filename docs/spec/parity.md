# StarUML parity

Every StarUML v7.1 feature checked against Aster. **Better** means Aster does it and does it better; **Later** means after v0.2 with no date; **Never** means deliberately out of scope.

| StarUML feature                                                                             | What StarUML does                                                                                                     | Aster                                                                                       | Status |
| ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------ |
| Class diagram                                                                               | Full UML 2 class notation                                                                                             | The v0.1 product                                                                            | v0.1   |
| Package diagram                                                                             | Packages, imports, merges                                                                                             | Packages ship in v0.1 as containers; the dedicated diagram with imports in v0.2             | v0.2   |
| Object diagram                                                                              | Instances, slots, links                                                                                               | Same classifiers, instance renderer                                                         | v0.1   |
| Use case diagram                                                                            | Actors, use cases, include/extend, subjects                                                                           | First new diagram type                                                                      | v0.2   |
| Sequence diagram                                                                            | Lifelines, messages, fragments                                                                                        | v0.3 with a PlantUML sequence dialect                                                       | Later  |
| Statechart diagram                                                                          | States, transitions, pseudostates                                                                                     | v0.3                                                                                        | Later  |
| Activity diagram                                                                            | Actions, flows, partitions                                                                                            | v0.4                                                                                        | Later  |
| Component and deployment                                                                    | Components, artifacts, nodes                                                                                          | v0.4                                                                                        | Later  |
| Composite structure, communication, timing, interaction overview, information flow, profile | The long tail of UML 2                                                                                                | Files with them round-trip untouched; no renderer planned                                   | Never  |
| SysML, ERD, flowchart, DFD, C4, BPMN, mind map, wireframe, AWS/GCP/Azure                    | Non-UML notations, mostly Pro tier                                                                                    | Out of scope; ERD is the only one worth revisiting                                          | Never  |
| Model/view split                                                                            | `Delete` removes a view; `Ctrl+Delete` removes from model; views of one element in many diagrams                      | Same semantics, same keys                                                                   | v0.1   |
| Drag from Model Explorer to diagram                                                         | Creates a view of an existing element                                                                                 | Drag from Outline, or "Add to diagram" in the palette                                       | v0.1   |
| QuickEdit                                                                                   | Double-click/Enter; expression syntax for members; `Ctrl+Enter` adds the next member                                  | Inline editing with live parse, autocomplete for types, plus the whole diagram as text      | Better |
| QuickEdit relationship shortcuts                                                            | Add sub-class, super-class, associated/aggregated/composited class, provided/required interface from the class itself | `L` + picker covers it; one-key "add sub-class" family in v0.2                              | v0.2   |
| Member expression syntax                                                                    | `[<<stereotype>>] [vis] name [:type] [[mult]] [=default]`; operations with params and return                          | Same grammar, superset                                                                      | v0.1   |
| Association ends                                                                            | Name, visibility, navigability, aggregation, multiplicity, ownership dot, order-of-ends                               | All but qualifiers                                                                          | v0.1   |
| Association class, n-ary, qualifiers                                                        | Advanced association forms                                                                                            | Round-trip only until v0.2                                                                  | v0.2   |
| Template parameters and bindings                                                            | Generics                                                                                                              | Round-trip only until v0.2                                                                  | v0.2   |
| Receptions, signals, ports, parts, connectors                                               | Composite-structure machinery                                                                                         | Round-trip only                                                                             | Later  |
| Tags and constraints as elements                                                            | Typed tags shown as `{tag=value}`; constraints with a specification                                                   | Round-trip in v0.1; editable in v0.2                                                        | v0.2   |
| Notes, note links, text                                                                     | Annotation elements                                                                                                   | In v0.1                                                                                     | v0.1   |
| Documentation field                                                                         | Markdown per element with preview                                                                                     | Markdown editor in the inspector; shown in Outline                                          | v0.1   |
| Hyperlinks, frames, images                                                                  | More annotation elements                                                                                              | v0.2                                                                                        | v0.2   |
| Stereotypes and profiles                                                                    | Text stereotypes; UML Standard Profile; profile diagrams                                                              | Text stereotypes in v0.1; profiles later                                                    | Later  |
| Model validation                                                                            | Async, rules UML001–057, results in a bottom panel                                                                    | The eleven class-diagram rules as a live warnings panel in v0.1; others with their diagrams | v0.1   |
| Find and Quick Find                                                                         | `Ctrl+F` text search; `Ctrl+P` finds elements, views, diagrams                                                        | One `⌘P` finder over elements and diagrams; `⌘F` in text view                               | v0.1   |
| Command Palette                                                                             | `Ctrl+Shift+P`                                                                                                        | `⌘K`, with `⌘⇧P` as alias                                                                   | v0.1   |
| Line styles                                                                                 | Rectilinear, oblique, roundrect, curve                                                                                | All four, mapped to `.mdj` `lineStyle` 0–3                                                  | v0.1   |
| Fill and line colour, font per element                                                      | Style Editor                                                                                                          | Fill and line colour in v0.1; font in v0.2                                                  | v0.1   |
| Stereotype display modes                                                                    | None, label, decoration, decoration+label, icon, icon+label                                                           | None and label in v0.1; icon modes (lollipops) in v0.2                                      | v0.2   |
| Show visibility / namespace / property / type / multiplicity / signature                    | Per-element toggles with shortcuts                                                                                    | Per-diagram defaults plus per-element overrides                                             | v0.1   |
| Suppress attributes / operations / literals                                                 | Hide compartments                                                                                                     | In v0.1                                                                                     | v0.1   |
| Auto resize, word wrap                                                                      | Sizing behaviours                                                                                                     | Auto-size always on with manual override; word wrap in v0.1                                 | v0.1   |
| Align, distribute, front/back                                                               | Format menu                                                                                                           | In v0.1, plus same-size                                                                     | v0.1   |
| Grid and snap                                                                               | Toggles                                                                                                               | In v0.1                                                                                     | v0.1   |
| Auto layout                                                                                 | Four directions                                                                                                       | ELK layered and orthogonal, four directions                                                 | v0.1   |
| Shadow, inherit style                                                                       | Decoration                                                                                                            | Shadow never; inherit style is the default behaviour                                        | Never  |
| Dark and light themes                                                                       | Two themes                                                                                                            | Plus high contrast and forced-colours                                                       | Better |
| `.mdj` open and save                                                                        | Native format                                                                                                         | Round-trip with unknowns preserved, ten public files in the test corpus                     | Better |
| Fragments                                                                                   | Export a subtree, import as a child                                                                                   | Import in v0.1; export in v0.2                                                              | v0.1   |
| Templates on new                                                                            | Five bundled templates                                                                                                | Template gallery                                                                            | v0.1   |
| Export PNG / JPEG / SVG, copy as image                                                      | Current or all diagrams                                                                                               | PNG, SVG, clipboard; JPEG never                                                             | v0.1   |
| PDF export                                                                                  | Page size, layout, name                                                                                               | Vector PDF                                                                                  | v0.1   |
| HTML docs                                                                                   | Publish the model as a site                                                                                           | v0.2                                                                                        | v0.2   |
| StarUML 1 `.uml` import                                                                     | Legacy                                                                                                                | Never                                                                                       | Never  |
| Mermaid                                                                                     | One-way text to diagram                                                                                               | Bidirectional PlantUML view; Mermaid export in v0.1, import in v0.2                         | Better |
| Multiple diagrams, Working Diagrams, next/previous                                          | Diagram tabs and shortcuts                                                                                            | Tabs, `⌘⇧]` / `⌘⇧[`                                                                         | v0.1   |
| Minimap, diagram thumbnails                                                                 | Overview panels                                                                                                       | v0.2                                                                                        | v0.2   |
| Relationships panel                                                                         | Lists relationships of the selection                                                                                  | In the inspector                                                                            | v0.1   |
| Model Explorer                                                                              | Tree, search, sort, stereotype text                                                                                   | Outline is also an editing surface                                                          | v0.1   |
| Cross-platform desktop app                                                                  | Electron, per-device licence, auto-update                                                                             | Installable PWA, no install rights needed, always current                                   | Better |
| Extensions and registry                                                                     | JavaScript extensions                                                                                                 | Later, after the model API settles                                                          | Later  |
| Code generation                                                                             | Java, C#, C++, Python via extensions                                                                                  | v0.4                                                                                        | Later  |
| CLI                                                                                         | Headless codegen, docs, images                                                                                        | Headless export via Node in v0.2                                                            | v0.2   |
| AI via MCP server                                                                           | Model generation from AI tools                                                                                        | Later                                                                                       | Later  |
| Documented keyboard shortcuts                                                               | A shortcuts page                                                                                                      | Every action has a key; `?` shows the sheet in-app                                          | Better |
| Canvas keyboard navigation                                                                  | None documented                                                                                                       | Spatial focus navigation, roving tabindex                                                   | Better |
| Screen reader support                                                                       | None                                                                                                                  | Outline and Text views as full editing surfaces; live announcements                         | Better |
| High contrast, reduced motion                                                               | None                                                                                                                  | Both, with forced-colours                                                                   | Better |
| Price and licence                                                                           | $129 / $199 per device, one-time; 30% educational                                                                     | Free, open source                                                                           | Better |

Sources: staruml.io, docs.staruml.io (user guide, class diagram, keyboard shortcuts, formatting, validation rules, pricing), checked 17 Oct 2026 against StarUML v7.1.1.
