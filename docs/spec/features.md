## Core user flows

1. **Start.** First visit: welcome canvas with a sample diagram and three cards (New diagram, Open `.mdj`, Recent). Returning visits open the last autosaved project. Layout preset and theme are remembered.
2. **Add a class.** `C` (or toolbox, or double-click empty paper) → class at the cursor with its name selected. `↩` commits and opens a new attribute line; `↩` again adds another; `Tab` jumps to operations; `Esc` ends. `I`, `E`, `D`, `P`, `N` do the same for interface, enum, data type, package, note.
3. **Edit compartments.** Double-click a line or select the class and `F2` to edit as UML text (`- balance: Money = 0`, `+ deposit(amount: Money): void`, `# {static} count: int`). Parsed live; a parse failure keeps the raw text with a thin warning underline and still saves. The Properties panel shows the same data as fields.
4. **Connect.** Drag from a node's edge handle onto another node → relationship picker at the drop point (`1`–`6`) → edge with sensible defaults. Click an edge to select; double-click near an end edits that end's multiplicity inline. Drag an edge midpoint to add a waypoint; drag a waypoint onto its neighbours to remove it. Keyboard: `L`, arrows to target, `↩`, pick kind.
5. **Open and save.** `⌘O` opens a `.mdj` (picker or drop anywhere). Everything understood appears at its StarUML coordinates; anything not understood is listed in a non-blocking notice and preserved on save. `⌘S` saves to the same file via File System Access; browsers without it download. Autosave to IndexedDB on every change; `⌘⇧S` saves a copy.
6. **Export.** `⌘⇧E`: PNG or SVG, 1× or 2×, transparent or white, whole or selection; copy-as-PNG button.

Undo threads through all of them with a toast naming the step ("Undo: delete Account").
