# Decisions

One line per deviation from `docs/spec/`, with the reason, added in the same change. Newest at the bottom. Format: `YYYY-MM-DD · area · what · why`.

- 2026-10-17 · tooling · Bits UI (headless) is the only UI library; shadcn-svelte rejected · two layouts and three themes need unopinionated chrome with library-owned ARIA and focus behaviour.
- 2026-10-17 · model · `Relationship.targetId` is the whole (diamond side) for aggregation and composition · matches StarUML's end2 and makes "connect part to whole" the gesture.
- 2026-10-17 · model · `EdgeLayout.waypoints` stores interior points only; border endpoints are recomputed · StarUML's first/last `points` are derived from node bounds and go stale when nodes move.
- 2026-10-17 · tooling · Vitest runs one node-environment project over `tests/unit`, no browser/component mode · nothing needs a DOM yet; add when a component test does.
- 2026-10-17 · tooling · CI runs Playwright on Chromium only · keeps the pipeline fast; add browsers when a browser-specific bug appears.
- 2026-10-17 · tooling · `bits-ui` → `runed` declares a peer on `@sveltejs/kit` ^2 while the project is on kit 3; warning accepted · build and check pass.
- 2026-10-17 · tooling · hand-authored `src/lib/model/types.ts` and `src/lib/commands/types.ts` are excluded from Prettier · they keep the owner's formatting; the tool must not rewrite files it may not edit.
- 2026-10-17 · tooling · `src/lib` is imported as `#lib/<file>.js` (full path), not `$lib` · SvelteKit 3 replaced the `$lib` alias with Node subpath imports, which do not resolve directory indexes.
- 2026-10-17 · fixtures · the three OOAD lab `.mdj` files are not available; the golden corpus will be public files only, and the extra grammar lines will be copied from those · owner does not have the lab files.
- 2026-10-17 · commands · `moveNode` takes `ids[]` and coalesces on the sorted id set, not a single element · nudging a multi-selection must be one undo step.
- 2026-10-17 · commands · a coalesced step keeps a flattened batch of inverses instead of merging deltas · generic for any coalescing command; a long drag undoes as one step of many tiny moves.
- 2026-10-17 · commands · undo and redo reselect the elements the step touched that are still on the diagram · gives Enter, arrows and Backspace a target straight after an undo; this is what `Command.touches` is for.
- 2026-10-17 · canvas · the keyboard router sits on a focusable `role="application"` container, with Svelte's two non-interactive-element a11y warnings suppressed there · the spec makes the diagram one Tab stop whose keys the app routes; it is not a fake button.
- 2026-10-17 · canvas · paper text uses a system humanist sans stack, not the bundled OFL font · font bundling belongs with export, where cross-OS identity matters.
- 2026-10-17 · ui · theme follows `prefers-color-scheme` only; no explicit light/dark/high-contrast switch yet · the `⌘⌥T` toggle and high-contrast tokens are a later slice.
- 2026-10-17 · ui · diagram tabs are Bits UI Tabs with the canvas area as the tabpanel · keeps the tab/tabpanel ARIA relationship real instead of empty panels.
- 2026-10-17 · tooling · e2e tests reselect nodes by `.class-node[data-name]` · nodes are not focusable until the M2 canvas keyboard model, so there is no role to query yet.
- 2026-10-17 · grammar · the property block accepts only `static`, `readOnly`, `derived` (attributes) and `static`, `abstract`, `query` (operations); any other property makes the line raw · the grammar leaves `props` open, and silently dropping an unknown property would lose data.
- 2026-10-17 · grammar · a member that is both static and abstract renders `{static}` as the prefix and `{abstract}` in the property block · the prefix slot holds one keyword, and this keeps the line round-tripping.
- 2026-10-17 · grammar · an unparseable literal keeps its text as the literal's name · `Literal` has no `raw` field in the hand-authored types.
- 2026-10-17 · grammar · an unparseable attribute or operation keeps its previous name (or the text) in `name` beside `raw` · `name` is required and the Outline needs a label.
- 2026-10-17 · i18n · messages live in `src/lib/i18n/en.json` and `t()` interpolates `{name}` placeholders · features.md asks for message files.
- 2026-10-17 · i18n · `?locale=pseudo` wraps every message in brackets and pads it with `~` by 30 % of its source length, placeholders included; the locale is rune state applied after hydration · the page is prerendered in English.
- 2026-10-17 · commands · `replaceMember` is the inverse of `setMemberText` and restores the exact previous member, raw text and documentation included · re-parsing the old line would lose documentation and canonicalise raw text.
- 2026-10-17 · canvas · ↩ on the name commits and opens a new line in the first compartment; ↩ on an empty new line ends editing; emptying an existing line deletes that member · keyboard.md says ↩ commits and starts the next line but is silent on the name and on empty lines.
- 2026-10-17 · canvas · Tab cycles name → each compartment → name, landing on a compartment's first line, or on a new line when it is empty · keyboard.md says "next compartment" without saying which line.
- 2026-10-17 · canvas · interfaces show operations, plus attributes only when they have some; enums show literals, plus attributes and operations only when present; data types show attributes, plus operations when present · features.md says "operations by default" for interfaces only.
- 2026-10-17 · canvas · the «interface» / «enumeration» / «dataType» keyword gives way to an explicit stereotype, so «primitive» is a data type with stereotype `primitive` · the model has no primitive flag; the codec will map `UMLPrimitiveType` to that.
- 2026-10-17 · canvas · type completion is a Bits UI Combobox on attribute and operation lines, opened after a colon, offering project classifiers plus String, int, long, double, float, boolean, char, void and Date as whole-line options · the spec does not list built-in types.
- 2026-10-17 · canvas · derived nodes carry Svelte Flow's last measured size as a hint, and each node gets a per-version copy of its classifier · without `measured` Svelte Flow hides fresh nodes for a frame (flicker, lost focus), and in-place mutation keeps old references so compartments would not re-render.
- 2026-10-17 · canvas · double-click zoom is off · double-click edits, per keyboard.md.
- 2026-10-17 · canvas · Esc with the completion list open closes the list; a second Esc ends editing · progressive Esc, as keyboard.md describes.
- 2026-10-17 · explorer · diagrams, packages and classifiers are siblings under the project, as in StarUML's Model Explorer, not nested under diagrams · an element can sit on several diagrams; relationship rows arrive with relationships.
- 2026-10-17 · explorer · ↩ or Space selects the row's element on the canvas, click selects, double-click returns focus to the canvas; single selection only · the tree is read-only until M2, and the ARIA tree pattern leaves activation to the app.
- 2026-10-17 · explorer · ⌘E opens the drawer when it is closed, then focuses the selected element's row · keyboard.md binds ⌘E to select-in-Outline while the drawer is hidden by default.
- 2026-10-17 · inspector · member rows edit the UML line as text, with a visibility select per attribute and operation that dispatches `setMemberText` with the re-rendered line · panel and inline editing must dispatch the same commands.
- 2026-10-17 · inspector · literals are edited with the member commands, so `setLiterals` has no UI caller yet · panel and inline editing must dispatch the same commands.
- 2026-10-17 · inspector · Text and Diagram tabs are present but disabled · they belong to later slices.
