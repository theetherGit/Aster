This tour draws an account, a savings account and a customer, links them, and saves the result as a `.mdj` StarUML opens. Every step is a key, and the keys on this page are the ones for your computer.

## 1. Start a diagram

Open [asteruml.app](https://asteruml.app/). There is nothing to install and no account. Choose **New diagram** (<Key k="⌘N" />). To work on a StarUML file instead, choose **Open file** (<Key k="⌘O" />) or drop the `.mdj` on the window.

<Shot name="welcome" alt="Aster's welcome page: New diagram and Open file on the left, the demo project and the Recent list on the right." />

<Aside type="tip" title="StarUML's layout">
  <Key k="⌘⇧L" /> switches to the Classic layout: StarUML's menus, Model Explorer, toolbox and editors in the places you know. Press it again to come back.
</Aside>

## 2. Make a class

Point at an empty spot and press <Key k="C" />. A class appears with its name selected.

1. Type `Account` and press <Key k="↩" />. The first attribute line opens.
2. Type `- balance: float = 0` and press <Key k="↩" /> for the next line, or <Key k="Tab" /> to move to the operations.
3. Type `+ deposit(amount: float): void`.
4. Press <Key k="Esc" /> when you are done.

<Shot name="chip" alt="A class named Account with the line - balance: float = 0 open for editing. The chip under it reads private · float · default 0, then the keys for the next line, the operations, and done." />

Lines are StarUML's member syntax. While you type, a chip under the class says how Aster reads the line. A line it cannot read is kept as you typed it, with an amber wavy underline, so nothing you write is lost.

Make two more the same way: `SavingsAccount` with `- rate: float`, and `Customer` with `- name: String`. <Key k="I" />, <Key k="E" /> and <Key k="D" /> make an interface, an enumeration and a data type; <Key k="N" /> makes a note.

More in [Classes and members](/guides/classes/) and [Member syntax](/reference/member-syntax/).

## 3. Connect them

Select `SavingsAccount`, then press <Key k="L" />. Move to `Account` with the arrow keys and press <Key k="↩" />. Pick the kind with its number:

| Key | Relationship |
| --- | --- |
| <Key k="1" /> | Association |
| <Key k="2" /> | Aggregation |
| <Key k="3" /> | Composition |
| <Key k="4" /> | Generalization |
| <Key k="5" /> | Realization |
| <Key k="6" /> | Dependency |

<Shot name="picker" alt="Linking Customer to Account: the relationship kind picker lists Association, Aggregation, Composition, Generalization, Realization and Dependency, with the keys 1 to 6." />

Press <Key k="4" />: a savings account is an account. The line runs from the class you selected to the one you picked, so the triangle points at `Account`. For an aggregation or composition, start from the part: the diamond goes on the whole.

Now link `Customer` to `Account` with <Key k="1" />, an association. With the line selected, the inspector on the right sets its role names and multiplicities.

More in [Relationships and notes](/guides/relationships/).

## 4. Edit in place

Double-click any name or line to edit it, or select it and press <Key k="F2" /> or <Key k="↩" />. <Key k="⌘↩" /> adds an attribute below the one you are on, and <Key k="⌘⇧↩" /> an operation, as in StarUML.

<Key k="⌘Z" /> undoes, up to 500 steps back, and the history survives a reload.

## 5. Tidy it

Press <Key k="⌘K" /> for the command palette, type `layout` and choose **Auto-layout: Layered, top to bottom**. Superclasses go above their subclasses, and nothing overlaps. Orthogonal layout draws right-angled lines instead.

Move a class by dragging it, or select it and nudge it with <Key k="⌘→" /> and the other arrows. <Key k="⌘G" /> shows the grid, and <Key k="⌘⇧G" /> snaps to it.

More in [Arrange a diagram](/guides/arrange/).

## 6. Check it

In the command palette, choose **Validation panel**. It lists what StarUML's [validation rules](/reference/validation/) would flag, such as two classes with the same name, and jumps to each one.

Choose **Text view (PlantUML)** to see the whole diagram as text. Edit the text and the diagram follows; edit the diagram and the text follows. More in [Edit as text](/guides/text-view/).

## 7. Save and hand in

Press <Key k="⌘S" />. A new project is saved in the browser, and the notice offers **Download .mdj**: that file opens in StarUML. A file you opened is written back to itself in Chrome and Edge. [Open and save](/guides/files/) says what each browser does.

<Key k="⌘⇧E" /> opens the export sheet:

- **Image**: PNG at 1× or 2×, or SVG, of the diagram or the selection.
- **PDF**: one page, A4, A3 or Letter.
- **Text**: Mermaid or PlantUML.
- **Project**: `.mdj` or Aster's own `.aster`.

<Shot name="export" alt="The export sheet on its Image tab: PNG or SVG, 1× or 2×, white or transparent background, selection only, the file name and size, Copy to clipboard and Download." />

<Key k="⌘⇧C" /> copies the diagram as a PNG, ready to paste into a report. More in [Export and share](/guides/export/).
